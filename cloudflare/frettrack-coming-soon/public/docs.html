Current release: v0.3.0

The Operational Shop Release unifies focused Guitar, Amplifier, and Keyboard repair benches with FretTrack's shared parts, purchasing, payments, printing, scheduling, messaging, photos, and history workflow.

It also includes isolated customer and job-sheet printing, accounting-safe work-order exclusion, production Stripe subscriptions, scheduled email, service reminders, loyalty, and the established shop, role, consent, quota, and billing safeguards.

Why these docs are here

GitHub Wiki is still useful for project history, but customer-facing help should be reachable without a GitHub account, GitHub asset access, or unmanaged browser policy exceptions. These pages keep the working shop guides on the public FretTrack domain.
